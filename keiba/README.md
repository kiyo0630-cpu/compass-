# keiba — 競馬予想シミュレーター（TARGET frontier JV データ）

`index.html`（コンパス）とは独立したサブプロジェクト。このフォルダ内で完結する。

## 構成

| パス | 内容 |
|---|---|
| `split_history.py` | TARGET「レース一覧成績」の大きな CSV を四半期ごとに分割して zip にする（Mac 側で実行） |
| `load_results.py` | レース一覧成績 CSV を読み込み、ベースライン（人気別・オッズ帯別回収率、市場確率の校正）を出す |
| `features.py` | 補正タイム（固定効果回帰）、文脈化した上がり 3F、馬ごとの履歴特徴量を作り `data/features.csv` に書く |
| `model_clogit.py` | 条件付きロジット（レース内 softmax）で「市場 + 特徴量」が「市場のみ」を上回るかをウォークフォワード検証 |
| `analyze_edge.py` | モデル B の改善をクラス・芝ダ・頭数・距離・競馬場・年・オッズ帯で分解（`results/edge_breakdown.csv`） |
| `eval_indices.py` | 出馬表形式 CSV（ZI・マイニング・対戦型マイニング入り）を溜めて指数の情報量を測る |
| `docs/research-v2.md` | 調査レポート（JV-Data の棚卸し、市場の知見、精度向上の工夫、仮説リスト） |
| `results/` | 検証結果（CSV） |
| `data/` | 入力データと中間ファイル。**git 管理外**（Google Drive 経由で受け渡し） |

## データの置き方

```
keiba/data/history/history_2016_Q1.csv ... history_2026_Q2.csv   ← レース一覧成績（cp932）
keiba/data/features.csv                                           ← features.py の出力
```

## 実行順

```
python3 load_results.py data/history        # ベースライン
python3 features.py                         # 特徴量テーブル（約 1.5 分）
python3 model_clogit.py                     # ウォークフォワード検証（約 1 分、data/predictions_test.csv も出す）
python3 analyze_edge.py                     # 改善の分解
```

依存は numpy と pandas のみ。

## 列の意味（データから確定したもの）

- クラスコード: 7 未勝利 / 15 新馬 / 23 1勝 / 43 2勝 / 67 3勝 / 115 リステッド / 131 OP特別 / 147 格付けなし重賞 / 163 G3 / 179 G2 / 195 G1
- コースコード: 0 芝（内・通常） / 8 芝外回り / 1 ダート
- 間隔: 前走からの週数（日数 ÷ 7 の四捨五入）
- PCI: 前半 600m 換算タイム ÷ 上がり 3F × 100 − 50（大きいほどスロー）
- レースID: 末尾 2 桁が馬番。レース単位のキーは末尾を落とす

## これまでの結果（2016-01〜2026-06、34,951 レース、ウォークフォワード 2020〜2026）

### 市場（確定単勝オッズ）
- 擬似 R² 0.255。オッズ帯別の勝率と市場確率は 30 倍まで一致し、100 倍以上だけ回収率 49% と買われ過ぎ。

### 単勝: 市場に特徴量を足す（v3、26 特徴量）
- レースあたり対数尤度の改善は 2020〜2026 で +0.0014〜+0.0078（平均 +0.0042）。全年プラス。擬似 R² で +0.001〜0.003。
- v3 の変更: Elo を着差（補正タイム差のシグモイド）ベースにしたところ t 値が 1 前後から 2〜3.4 に上がり、安定して効くようになった。
  ペース×位置取りは連続量の交互作用を捨て、展開区分ダミーにしたところ「前走スローを先行」が t 3〜5 で安定（市場が割り引き過ぎ）、
  「前走ハイペースを後方」が負（市場が買い過ぎ）、「前走ハイペースを先行（展開不利）」はゼロ（市場が織り込み済み）。
- 特徴量のみのモデルは擬似 R² 0.15〜0.18 で市場（0.25）に遠く及ばない。「市場に足す」設計が正しい。
- 年をまたいで符号が安定し |t|>3 の特徴量: 文脈化した上がり 3F、過去の複勝率（負: 市場が過大評価）、馬齢（負）、
  レースレベル (a)(b)、前走人気、直近 3 走の最良補正タイム、間隔。
  脚質×先行型頭数、斤量、芝ダ替わりは有意ではない。
- 期待値ベッティング（確定オッズ、50 倍以下）: EV≥1.0 で 8,250 口 104.5%、EV≥1.1 で 2,104 口 116.0%（標準誤差 約 6%）。確定オッズ基準なので上限値。

### 改善はどこに集中しているか（analyze_edge.py、テスト年 2020〜2026）
- クラス別のレースあたり ΔLL: 未勝利 +0.0087、1 勝 +0.0051、3 勝 +0.0035、2 勝 +0.0001、新馬 −0.0008、G3 −0.0103、G2 −0.0086、OP(L) −0.0042。
  下級条件に情報があり、重賞ではモデルがむしろ市場を悪化させる（件数は少ない）。新馬は履歴が無いので当然ゼロ。
- 芝ダ: ダート +0.0074、芝 +0.0014。距離: 1400m 以下 +0.0059 が最大。頭数: 17〜18 頭は +0.0011 と小さい。
- EV≥1.1 の単勝回収率: 未勝利 117%（n=807, SE 15）、ダート 126%（n=1,054, SE 15）、芝 106%（n=1,050, SE 13）。
- 「モデルが市場より 15% 以上高く評価」だけでは回収率 90〜98% で 100% に届かない。期待値の閾値が必要。

### 3 着内
- 市場勝率から Harville 式（割引 λ=0.8 が毎年最良）で作った 3 着内確率が基準。特徴量を足すと 1 頭あたり +0.0010〜+0.0019 の改善（全年プラス）。
- 単勝モデルの勝率を Harville で 3 着内に変換しても市場基準を超えない。3 着内は別モデルが必要。

### 補正タイム（馬の固定効果つき）
- 斤量 +0.036 秒/kg、距離 1600m から 400m 延びるごとに +0.022 秒/kg 加算。残差 SD 1.06 秒、馬効果 SD 1.13 秒。
- 上がり 3F: PCI 1 ポイント上昇で −0.27 秒、4 角位置が後方ほど速い（+0.70 秒/位置 100%）。
