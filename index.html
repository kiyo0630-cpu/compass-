クラウド同期 複数端末で同じ手帳を使う（GitHub Gist・非公開）

トークンの作り方
GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)。スコープは gist のみにチェックして生成し、表示された ghp-… で始まる文字列をここに貼り付けます。トークンはこの端末の中だけに保存され、同期データやバックアップファイルには含まれません。
起動時に自動で取り込み、変更は数秒後に自動でクラウドへ送ります。2台目の端末では、同じトークンと上記のGist IDで接続してください。
左上のバッジが「同期保存」の環境どうし（例：PCとスマホ、それぞれのブラウザでclaude.aiを開いた場合）は、同じ手帳データを自動で共有します。「この端末に保存」の場合は端末ごとの保存になるため、「書き出す／読み込む」で持ち運びとバックアップができます。消去は元に戻せません。
