このページの読み方

  • データの出どころ: GitHub Actions が Cloudflare Radar から取得したスナップショット（attack-map/data/latest.json）を、取得のたびに attack-map/data/history/YYYY-MM.jsonl に 1 行ずつ追記したものです。各行は「直近 24 時間」の集計値なので、隣り合う時刻の値は窓が重なり、なめらかに変わります。
  • シェアの意味: 日本を標的とする攻撃のうち、その国の IP から来た割合（%）です。国は送信元 IP の地理情報で、ボットネットや踏み台を含みます。
  • 色: 国ごとに固定で、フィルタを変えても同じ国は同じ色です。上位 8 か国以外は灰色です。
  • 時刻: すべて日本時間（JST）で表示しています。
