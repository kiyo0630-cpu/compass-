    このページの読み方

    • 何を見ているか: 「日本を標的（宛先）とする攻撃」の送信元 国・地域の構成比です。国別シェアは Cloudflare Radar（L7 HTTP DDoS と L3/4 DDoS の上位送信元）などから取得し、地図の矢印とフィードはそのシェアに比例してランダム生成しています。1 本の矢印が 1 件の実際の攻撃を表すわけではありません。
    • 「国」の意味: 送信元 IP アドレスの地理情報です。多くはボットネットに乗っ取られた機器やレンタルサーバーからの通信で、その国の政府や国民が攻撃者という意味ではありません。攻撃者は踏み台を使うため、本当の発信地は分かりません。
    • 攻撃を受けている側: 被害を受けた個別の IP アドレスやドメインは公開されません（被害者側が公表しないため）。公開データで分かるのは「日本のどの業種・分野が狙われているか」までです。自分が管理するドメインへの攻撃は、Cloudflare のゾーン分析やサーバーのログから集計して表示できます。
    • リアルタイム性: ライブデータの最短集計単位は直近 1 時間で、ページの更新間隔と GitHub Actions のスケジュール（既定で毎時）に依存します。「デモ」表示は NICTER 観測レポートなど公開統計の傾向を参考にした概算の参考値で、実測値ではありません。
