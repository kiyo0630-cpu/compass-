# Eカード — 極限心理戦（スマホ縦画面特化）

漫画「カイジ」の Eカード を題材にした、プレイヤー対 CPU の心理戦 Web アプリ。
スマートフォン縦画面（`100dvh`・スクロールなし）で片手プレイできるよう最適化しています。

## ルール

- 王様側: 王様 1 枚 + 市民 4 枚 ／ 奴隷側: 奴隷 1 枚 + 市民 4 枚
- 王様 ＞ 市民、市民 ＞ 奴隷、奴隷 ＞ 王様。市民同士は引き分けで次ターンへ（最大 5 ターン）
- 毎ターン **奴隷側が先に** 伏せ、王様側が後に伏せる。双方が出したら 1.5 秒のタメの後に同時オープン
- **5 勝先取**。1 セットごとに王様側／奴隷側を交代
- **奴隷ボーナス**（スタート画面で切替・既定はオフ）: 奴隷側でセットを取る（＝奴隷で王を討つ）と一気に 2 勝分。CPU も同じ条件

## 心理戦

- **CPU の表情シグナル**: CPU は毎ターン、出す手を決めた時点の表情を見せる。
  55% は本音（勝負手の王様／奴隷なら「冷や汗」「指先の震え」、市民なら「不敵な笑み」「余裕」）、
  20% は逆を演じるブラフ、25% は「無表情」「沈黙」で何も読ませない（`src/game/logic.ts` の `makeTell`）
- **CPU の性格変化**: セット開始時のスコアで特殊カードを切るタイミングが変わる（`cpuStyleFor` / `SPECIAL_RATE`）

  | 状況 | スタイル | 1〜4 ターン目に特殊カードを切る確率 |
  |---|---|---|
  | 通常 | 標準 | 20% / 40% / 60% / 80% |
  | CPU が負け越し | 速攻（焦り） | 45% / 60% / 75% / 90% |
  | CPU がこのセットを取れば勝ち | 慎重（待ち） | 6% / 15% / 40% / 75% |

  標準以外のときはセット開始の画面に一言ヒントが出る。5 ターン目は残り 1 枚なので確定
- **捨て札トラッカー**: 場の左上に消費された市民、右上に「相手の残り手札に王様／奴隷が含まれる割合（1/N）」を表示

## 演出

- PK 風スコアボード（勝ち: 黄金の天使、負け: 血色の悪魔、引き分け: `-`、進行中: 点滅する破線サークル、2 勝分は `×2` バッジ）
- オープン直前のタメでカードの端がじわりと持ち上がり、スローモーション気味に 3D フリップ
- **王様 vs 奴隷の激突**は画面シェイク＋赤い閃光＋稲妻＋雷鳴。それ以外の決着は軽い衝撃
- CPU 思考中・オープン直前・3 ターン目以降は「ざわ…」が画面の端から浮かんで消える
- 結果オーバーレイに両者のカードを大きく並べて表示。最終勝利は地下財宝、最終敗北は地下牢の一枚絵
- Web Audio API で心拍音をシンセ生成（ターン進行と REVEAL 直前で BPM 上昇）。外部音源ファイル不要

## 操作

- 手札をタップで選択 →「このカードを出す」。選択中のカードをもう一度タップしても出せる
- 手札を**上にスワイプ（フリック）**して場に投げても出せる
- ヘッダーのアイコンでミュートと振動を個別に切替（設定は端末に保存）
- **振動**: 鼓動・カードを出した瞬間・決着に連動。Android の Chrome などは Vibration API で動く。
  iPhone の Safari は Vibration API に非対応なので、iOS 18 以降のスイッチ用触覚フィードバックを代用している
  （強さや長さは指定できず、OS のバージョンによっては何も起きない）

## PWA（ホーム画面に追加・オフライン起動）

- `public/manifest.webmanifest` とアイコン（`icon-192.png` / `icon-512.png` / `icon-maskable-512.png` / `apple-touch-icon.png`）
- `public/sw.js` が初回訪問時に必要なファイルを保存するので、2 回目以降は圏外でも起動できる。
  `index.html` はネットワーク優先なので、公開した更新はオンラインで開けばすぐ反映される
- iPhone: Safari の「共有 → ホーム画面に追加」／ Android: Chrome の「アプリをインストール」

## フォルダ構成と公開

- `e-card-src/` … ソースコード（このフォルダ）
- `e-card/` … `npm run build` の出力。GitHub Pages で `https://kiyo0630-cpu.github.io/compass-/e-card/` として配信される
- `.github/workflows/e-card-build.yml` … main の `e-card-src/` が変わると自動でビルドして `e-card/` をコミットする

## 開発

```bash
cd e-card-src
npm install
npm run dev -- --host   # 同じ Wi-Fi のスマホから Network の URL で開ける
npm run lint && npx tsc -b
npm run build           # ../e-card に出力（base は './' なのでサブディレクトリ配信可）
```

開発サーバー限定の確認用パラメータ（本番ビルドには含まれない）:

- `?debug=win` / `?debug=lose` … 最終結果画面を直接表示
- `?cpu=special` / `?cpu=citizen` … CPU の手を固定（激突演出や引き分け進行の確認用）

技術スタック: React + TypeScript + Vite + Tailwind CSS v4 + Framer Motion + Lucide React
